  kubectl get pods -n {{ .Release.Namespace }}

  kubectl logs -n {{ .Release.Namespace }} -l app.kubernetes.io/component=backend -f

View the API docs:
  kubectl -n {{ .Release.Namespace }} port-forward svc/{{ include "project-clinq.fullname" . }}-backend 8000:8000
